# NOVA Laptop Landing Page

## About the Project

NOVA is a responsive laptop product landing page made as part of the Web Development Week 02 Minor Project.

The page presents a laptop concept with a simple layout, product information, features, benefits, customer reviews, and an enquiry section.

## Features

- Responsive navigation bar
- Product introduction and laptop image
- Product features displayed using grid cards
- Benefits section
- Sample customer reviews
- Call-to-action section
- Footer with navigation and contact links

## Technologies Used

- HTML5
- Tailwind CSS
- CSS Flexbox
- CSS Grid
- Responsive Design

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Make sure you have an internet connection for the Tailwind CDN and laptop image.

## Project Note

NOVA is a fictional product created for learning and demonstration purposes. The reviews are examples, not verified customer testimonials.
